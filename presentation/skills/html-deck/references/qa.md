# QA：截圖檢查、審查格式、技術陷阱

**沒有實際截圖看過，就不能說「已檢查」。** 只讀過原始碼的項目要列在「未驗證」。

## 1. 自動檢查（每次大改後跑）

```bash
npm i playwright-core   # 不要跑 playwright install；用環境內建的 Chromium
node scripts/shoot.cjs index.html shots --exe /path/to/chromium --wait 1500
```

輸出 `shots/slide-NN.png`、`contact-sheet.png`、`report.txt`，會標出：
- 元素超出 1600×900 舞台（`出界`）
- `overflow:hidden` 的容器內容被裁（`內容被裁切`）
- 段落最後一行疑似只有 1–2 個字（`疑似孤字`）
- JS 錯誤、console error、載入失敗的資源

允許超出舞台的裝飾元素加 `data-allow-overflow`。

**一定要打開截圖看**，尤其是 contact sheet：一眼看出節奏是否單調、哪幾頁版型重複、哪頁太擠或太空。

## 2. 人工走查（交付前）

- [ ] 只用鍵盤從第一頁翻到最後一頁；N（備註）、F（全螢幕）、Esc（關燈箱）都正常
- [ ] 直接開 `#中間頁`、`#最後一頁`，狀態正確
- [ ] 連按方向鍵，動畫不卡、不殘留
- [ ] 視窗縮成小筆電大小（1280×720）與超寬（2560×1080）都等比縮放、沒有捲軸
- [ ] 瞇眼看每一頁：只有一個視覺焦點
- [ ] 每頁都有講者備註
- [ ] 斷網開 standalone 檔：圖示、圖片、Demo 都在
- [ ] `prefers-reduced-motion` 開啟時走一遍
- [ ] 列印預覽（PDF 匯出）每頁一張、沒有空白頁
- [ ] Demo 用最壞資料試：很長的名稱、0 筆、1 筆、大量資料

## 3. 審查回報格式（使用者要求 review 或交付前自我審查）

順序：無障礙 → 版面 → 文案 → 字體 → 細節，每個問題只歸一類。

| # | 嚴重度 | 頁碼／元素 | 現況 | 修改為 | 原因 |
| --- | --- | --- | --- | --- | --- |

- **HIGH**：看不清楚（對比不足）、內容被裁或出界、導覽壞掉、Demo 當掉、離線缺素材、資料錯誤或捏造
- **MEDIUM**：層級混亂、版型重複、孤字、標題不對齊、文案太長
- **LOW**：細節打磨

修法要寫成具體數值（「行高 1.5 → 1.75」「對比 3.1:1 → 改用 --text-2 達 6.2:1」），不寫「再調整一下」。
快速模式最多 5 條、完整模式最多 15 條；不要湊數。最後附：考慮過但不改的項目、已驗證／未驗證清單、2–4 個優點、影響最大的一個修改、結論（可交付／需修改／阻擋）。

給自己的評語格式：「觀察 → 影響 → 建議」。

## 4. 無障礙底線

- 內文對比 ≥ 4.5:1，大字（24px+ 或 19px+ 粗體）與圖示 ≥ 3:1；投影會洗淡顏色，關鍵文字盡量 ≥ 7:1。
- 不只靠顏色表達狀態（加圖示、文字或形狀）。
- 導覽按鈕用原生 `<button>`，純圖示按鈕加 `aria-label`；`:focus-visible` 有 ≥ 2px 的焦點框。
- 投影片標題用真正的標題標籤（h1/h2/h3）。
- 自動播放的東西都要能停。

## 5. 已踩過的技術陷阱

| 症狀 | 原因 | 解法 |
| --- | --- | --- |
| 元素進場後位置跑掉、hover 失效 | 進場動畫用 `transform`，覆蓋了元素自己的 transform | 進場改用 `translate` 屬性 |
| 某個圖示突然變大或變色 | 選擇器太寬（`.sec .n svg` 抓到別的 svg） | 用 `>` 限定直接子元素 |
| 兩個元件樣式互相污染 | class 名稱撞名（`.ghost` 同時是按鈕和裝飾） | 元件 class 加前綴或改名（`.medal`、`.ghost-btn`） |
| 圖示全部不見 | CDN（unpkg）被擋或離線 | `inline-icons.cjs` 內嵌 |
| 開本機 HTML 時 Demo 空白 | `file://` 擋 module script | 建置後內嵌 JS／CSS |
| 線上網站在 iframe 裡空白 | `X-Frame-Options`／登入需要第三方 cookie | 離線 Demo＋新分頁備案 |
| 手機版作品集可以左右滑 | 某個元素寬度超出 | `html,body{overflow-x:clip}`，表格包捲動容器，`min-width:0` |
| 數字跳動 | 比例字寬 | `tabular-nums` |
| 截圖檢查截到半透明元素 | 動畫還沒跑完 | `--wait` 拉長到動畫總長＋300ms |
