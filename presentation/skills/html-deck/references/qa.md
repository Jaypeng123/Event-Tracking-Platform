# QA：截圖檢查、人工走查、審查格式、技術陷阱

**沒有實際看過截圖，就不能說「已檢查」。** 只讀過原始碼的項目列在「未驗證」。

## 1. 自動檢查（每次大改後跑）

```bash
npm i playwright-core lucide   # 不要跑 playwright install；用環境內建的 Chromium
node scripts/shoot.cjs index.html shots --exe /path/to/chromium --wait 1500
```

輸出 `shots/slide-NN.png`、`contact-sheet.png`、`report.txt`，會標出：
- 元素超出 16:9 舞台（`出界`）
- `overflow:hidden` 容器的內容被裁（`內容被裁切`）
- 段落最後一行疑似只有 1–2 個字（`疑似孤字`）
- JS 錯誤、console error、載入失敗的資源

允許超出舞台的裝飾加 `data-allow-overflow`。`--wait` 要大於該頁動畫總長＋300ms。

**一定要打開截圖看**，尤其是縮圖總覽：一眼看出節奏是否單調、哪幾頁版型重複、哪頁太擠或太空、視覺焦點是否每頁只有一個。

## 2. 人工走查（交付前）

- [ ] 只用鍵盤從第一頁翻到最後一頁；N（備註）、F（全螢幕）、Esc（關閉）正常
- [ ] 直接開 `#中間頁`、`#最後一頁`，狀態正確
- [ ] 連按方向鍵，動畫不卡、不殘留
- [ ] 視窗縮成 1280×720、拉成 2560×1080，等比縮放且沒有捲軸
- [ ] 瞇眼看每一頁：只有一個焦點，層級成立
- [ ] 每頁都有講者備註；照備註計時試講
- [ ] 斷網開單檔版：圖示、圖片、Demo、字體都在
- [ ] `prefers-reduced-motion` 開啟時走一遍
- [ ] 列印預覽（匯出 PDF）每頁一張、沒有空白頁、隱藏元素都顯示
- [ ] 投影或螢幕分享環境下看一次對比（淺灰字、細線最容易消失）
- [ ] Demo 與資料頁用最壞資料試：很長的名稱與 email、0 筆、1 筆（單複數）、大量資料、非拉丁文字、缺圖

## 3. 審查回報格式

使用者要求 review，或交付前自我審查時使用。順序：無障礙 → 版面 → 文案 → 字體 → 細節，每個問題只歸一類。

| # | 嚴重度 | 頁碼／元素 | 現況 | 修改為 | 原因 |
| --- | --- | --- | --- | --- | --- |

- **HIGH**：看不清（對比不足）、內容被裁或出界、導覽壞掉、Demo 當掉、離線缺素材、資料錯誤或捏造
- **MEDIUM**：層級混亂、版型重複、孤字、標題不對齊、文案太長、動態干擾閱讀
- **LOW**：細節打磨

規則：
- 修法寫具體數值（「行高 1.5 → 1.75」「對比 3.1:1 → 改用次文字色達 6.2:1」），不寫「再調整一下」。
- 同一個根本原因合成一列，列出所有出現位置。
- 快速模式最多 5 條（只列 HIGH／MEDIUM），完整模式最多 15 條；不要湊數。
- 最後附：考慮過但不改的項目（1–5 個）、已驗證／未驗證清單、2–4 個做得好的地方、影響最大的一個修改、結論（可交付／需修改／阻擋）。
- 審查預設只讀不改；使用者要求才動手修，修完重跑相關檢查。

## 4. 給簡報的設計評語（使用者要回饋時）

- 先問清楚階段：大綱階段只談故事與結構，草稿階段談節奏與版面，定稿階段才談像素、無障礙與細節。
- 格式用「觀察 → 影響 → 建議」，或「我喜歡／我希望／如果」。
- 給可執行、可量測的意見（「這頁有 12 個項目，建議拆成兩頁或分 3 組」），不給偏好（「我不喜歡藍色」）。

## 5. 無障礙底線

- 內文對比 ≥ 4.5:1，大字（24px+ 或 19px+ 粗體）與圖示 ≥ 3:1；投影環境關鍵文字盡量 ≥ 7:1。
- 不只靠顏色表達狀態或分類（加圖示、文字或形狀）。
- 導覽按鈕用原生 `<button>`，純圖示按鈕加 `aria-label`；`:focus-visible` 有 ≥ 2px、對比 ≥ 3:1 的焦點框，不加動畫。
- 觸控目標 ≥ 44px（桌面 ≥ 40px）。
- 投影片標題用真正的標題標籤；換頁時用 `aria-live` 播報「第 N 頁：標題」。
- 自動播放的東西都要能停；不做快速閃爍。

## 6. 已知技術陷阱

| 症狀 | 原因 | 解法 |
| --- | --- | --- |
| 元素進場後位置跑掉、hover 失效 | 進場動畫用 `transform`，覆蓋元素自己的 transform | 進場改用 `translate` 屬性 |
| 某個圖示突然變大或變色 | 選擇器太寬，抓到別的元素 | 用 `>` 限定直接子元素 |
| 兩個元件樣式互相污染 | class 名稱撞名 | 元件 class 加前綴或改名 |
| 圖示全部不見 | CDN 被擋或離線 | 用 `inline-icons.cjs` 內嵌 |
| 圖示內嵌腳本改錯地方 | 範例 `<script>` 寫在 HTML 註解裡 | 註解裡不要放 `<script id="icons">` 或 CDN 標籤 |
| 開本機 HTML 時 Demo 空白 | `file://` 擋 module script | 建置後內嵌 JS／CSS |
| 線上網站在 iframe 裡空白 | `X-Frame-Options`／需要第三方 cookie | 離線 Demo＋新分頁備案 |
| 卡片中段一大塊空白 | 卡片被拉高、內容只有一兩行 | 大圖示徽章或圖片填滿，或改用不拉伸的版型 |
| 截圖檢查截到半透明元素 | 動畫還沒跑完 | `--wait` 拉長 |
| 列印 PDF 一片空白 | 內容只靠動畫顯示 | `@media print` 強制顯示 |
| 長頁在手機可以左右滑 | 某元素寬度超出 | `overflow-x:clip`、`min-width:0`、表格包捲動容器 |
| 數字跳動、欄位對不齊 | 比例字寬 | `tabular-nums` |
| 中文行尾只剩一個字 | 自動換行 | 改寫、調寬或手動斷行 |
