# 動態與互動

簡報的動態有四個用途：**引導閱讀順序、說明變化或因果、營造主題氛圍、在高峰給記憶點**。說不出用途就不要動。

這份講「怎麼動才對」（關卡、參數、規則）；「可以做哪些互動」見 `interactions.md` 的強度刻度與配方庫。

## 1. 依簡報類型決定動態量

下表是預設傾向，對應 `interactions.md` 的強度：克制≈1–2、解釋型≈2–3、精緻≈3–4、玩心／展演≈4–5。使用者明確要求更多互動時以使用者為準。

| 類型 | 傾向 | 說明 |
| --- | --- | --- |
| 成果報告、研究、內部會議 | 克制 | 換頁淡入淡出即可，資料不為裝飾而動 |
| 技術分享、教學 | 解釋型 | 只在說明步驟、流程、因果時動 |
| 設計分享、作品集、提案、發表 | 精緻 | 可有進場編排與一次記憶點，仍要短、要有理由 |
| 兒童、創意、活動、工作坊暖場 | 玩心 | 可有彈性與驚喜，但每頁內容仍要靜態可讀 |

## 2. 頻率關卡

| 觸發頻率 | 處理 |
| --- | --- |
| 每次換頁（講者連按方向鍵） | 短、穩定、一致：淡入淡出或小位移，≤ 450ms；可被打斷，連按不能排隊卡住 |
| 每頁一次（揭示該頁重點、圖表長出來） | 可以設計，但服務內容；整份不要每頁都用同一招 |
| 全場一次（封面、高峰、結尾） | 這裡才放記憶點 |

列出動畫候選時要大量否決，大部分會被刪掉，這是正常的。

## 3. 參數

```css
--ease-out:    cubic-bezier(.23,1,.32,1);   /* 進場、揭示（預設） */
--ease-in-out: cubic-bezier(.77,0,.175,1);  /* 已在畫面上的元素移動、切換 */
--ease-drawer: cubic-bezier(.32,.72,0,1);   /* 面板、燈箱 */
```

- 只動 `transform`、`translate`、`opacity`、`clip-path`（擦除、揭示）、少量 `filter: blur`。不動 width、height、top、left；不寫 `transition: all`。
- 介面回饋（hover、按下、開關面板）150–250ms；進場 300–500ms，說明型可再長；離場比進場短（約一半）且更含蓄。
- 進場：opacity＋12–20px 位移，必要時加 2–4px blur。不從 `scale(0)` 開始，最小 0.95。
- 錯開（stagger）：每個 50–90ms，只用在有順序意義的同一組元素；一頁最多 5–6 個；同一頁不要兩組都錯開。
- 不用 bounce／elastic（玩心型簡報例外）；不用預設 `ease`／`linear`（連續循環除外）。
- 按下回饋 `scale(.96–.98)`；hover 效果寫在 `@media (hover:hover) and (pointer:fine)` 裡。
- 延遲出現的元素要設 `animation-fill-mode: backwards` 或初始樣式，避免先閃一下再消失。

## 4. 簡報專屬技術規則

- **進場用 `translate` 屬性，不用 `transform`**：元素本身常有 transform（置中、旋轉、hover），用 transform 做進場會互相覆蓋。
- **可直接跳頁**：任何一頁、任何步驟都要能直接到達（`#12`、End、往回翻）並顯示正確的最終狀態；互動元件在 `enter` 事件裡重設。
- **方向一致**：往後翻和往前翻的轉場方向相反；元素從哪裡進來就從哪裡離開。
- **列印與縮圖安全**：初始隱藏的元素在 `@media print` 強制顯示；內容不能只靠動畫才出現（headless 截圖、背景分頁時動畫可能不會跑）。
- **不在畫面上就暫停**：canvas 背景、輪播、影片、計時器在非作用頁停止。
- **自動播放要能停**：使用者點擊就停止輪播；影片要有暫停方法。
- **`prefers-reduced-motion: reduce`**：位移、錯開、視差、自動播放關閉，只留短淡入淡出或直接顯示。也處理 `prefers-reduced-transparency`（毛玻璃改實心）。

## 5. 好用的簡報動態模式

| 模式 | 用在 |
| --- | --- |
| 依序揭示 | 原因、步驟、清單：讓觀眾跟著講者的順序看 |
| 步驟同步檢視器 | 流程畫面：步驟亮起、對應畫面交叉淡入 |
| 狀態切換 | before/after、開關前後：點一下切換，文字跟著換 |
| 前後滑桿 | 兩張圖的視覺差異：用 clip-path 拖曳比較 |
| 模擬器 | 解釋機制（快取、排隊、額度、重試）：按「執行」看數字變化 |
| 線條繪製 | 流程圖、路徑：SVG `stroke-dashoffset` 依序畫出 |
| 數字跳動 | 只在數字是重點且真實時；用等寬數字 |
| 連鎖亮起 | 結論頁把 3–5 個關鍵詞依序亮起成一句話 |
| 封面視差／傾斜 | 只在封面，幅度小，游標離開就回正 |

## 6. AI 味動態（出現就刪）

- 每個標題、段落都淡入上移（靜態文字不需要進場動畫）
- 每頁都是同一種錯開動畫、兩組以上清單同時錯開
- 每個元素 hover 都放大或發光
- 永遠在呼吸、閃爍、脈動的指示點
- 每個進場都加 blur
- 背景動得比內容還搶眼、滿版持續移動
- 工具型操作（翻頁按鈕、備註開關）也加花俏動畫

## 7. 檢查方式

- DevTools → Animations 面板放慢到 10% 看曲線與順序；隔天再用新的眼光看一次。
- 連按方向鍵 10 次：不卡、不排隊、不殘留半透明元素。
- 開 `prefers-reduced-motion`（DevTools → Rendering）走一遍。
- 直接開 `#最後一頁`、`#中間某頁`，狀態正確。
