# 動態與互動

簡報的動態只有三個用途：**引導視線順序、說明因果或狀態變化、在高峰給一點驚喜**。沒有這三個理由，就不要動。

## 1. 先過頻率關卡

| 觸發頻率 | 處理 |
| --- | --- |
| 每次換頁都會發生（進場、換頁轉場） | 短、穩定、一致：opacity + 小位移，0.4–0.6s；不要花樣。 |
| 每頁一次（該頁重點的揭示、圖表長出來） | 可以有設計，但要服務內容。 |
| 全場一次（封面、Demo 開場、結尾金句） | 這裡才放「記憶點」。 |
| 講者連按方向鍵 | 動畫必須可被打斷；連按時不能卡住或排隊。 |

挑動畫機會時要大量否決：列出候選，大多數會被刪掉，這是正常的。

## 2. 參數

```css
--ease-out:    cubic-bezier(.23,1,.32,1);   /* 進場、揭示（預設） */
--ease-in-out: cubic-bezier(.77,0,.175,1);  /* 在畫面上移動、切換 */
--ease-drawer: cubic-bezier(.32,.72,0,1);   /* 面板、燈箱 */
```

- 只動 `transform`、`translate`、`opacity`、`clip-path`（擦除）、`filter: blur`（少量）。不動 width、height、top、left；不寫 `transition: all`。
- 介面回饋（hover、按下、開關面板）≤ 250ms；元素進場 400–600ms；離場比進場短（約一半）且更含蓄。
- 進場：opacity 0→1＋位移 12–22px，可加 2–4px blur→0。**不要用 `scale(0)`**，最小從 0.95 開始。
- 錯開（stagger）：每個元素 50–90ms，只用在同一組有順序意義的元素（例如三個原因）；一頁最多錯開 5–6 個。
- 不要 bounce／elastic。
- 按下回饋 `scale(.96–.98)`；hover 只在 `@media (hover:hover)` 裡寫。

## 3. 簡報專屬的技術規則

- **進場動畫用 `translate` 屬性，不用 `transform`**：元素本身常有 `transform`（置中、旋轉、hover 放大），用 `transform` 做進場會互相覆蓋。
- **可直接跳頁**：每頁、每個步驟的狀態要能直接到達（`#12` 開啟、按 End、往回翻），不能依賴前一頁的動畫跑完。互動元件在 `slide.addEventListener("enter", …)` 裡重設狀態。
- **列印與縮圖安全**：初始隱藏的元素在 `@media print` 要強制顯示；截圖 QA 要等動畫跑完。
- **不在畫面上就暫停**：canvas 背景、輪播、計時器在非作用頁停止，省 CPU，避免投影時掉幀。
- **自動輪播要可暫停**：使用者點擊任何步驟就停止自動播放。
- **`prefers-reduced-motion: reduce`**：位移與錯開關閉，只留淡入淡出或直接顯示；背景動畫停止。這是必要的，不是選配。

## 4. 好用的簡報動態模式

| 模式 | 用在 |
| --- | --- |
| 依序揭示（stagger） | 原因、步驟、清單：讓觀眾跟著講者的順序看。 |
| 步驟同步檢視器 | 流程截圖：左邊步驟亮起，右邊截圖交叉淡入，可自動輪播。 |
| 狀態切換 | before/after、設定前後：點一下切換，文字跟著換（`data-on`／`data-off`）。 |
| 模擬器 | 解釋機制（快取、重試、額度）：按「執行」看計數器變化。 |
| 連鎖亮起 | 結論頁把 3–5 個關鍵字依序亮起，形成一句話。 |
| 封面視差／傾斜 | 只在封面，幅度小（±8°），游標離開就回正。 |
| 線條繪製 | 流程圖用 SVG `stroke-dashoffset` 畫出來，比 Lottie 輕。 |

## 5. AI 味動態（出現就刪）

- 每個區塊都是同一種淡入上移
- 每個元素 hover 都放大或發光
- 永遠在跳動的指示點、到處 blur
- 錯開動畫灑滿整頁（10 個以上元素依序出現）
- 靜態內文也在動
- 背景元素動得比內容還搶眼

## 6. 檢查方式

- DevTools → Animations 面板，放慢到 10% 看每一段的曲線與順序。
- 連按方向鍵 10 次，確認不會卡住、不會殘留半透明元素。
- 開 `prefers-reduced-motion`（DevTools → Rendering）走一遍。
- 直接開 `#最後一頁` 和 `#中間某頁`，確認狀態正確。
