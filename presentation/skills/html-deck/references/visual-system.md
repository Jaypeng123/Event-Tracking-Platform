# 視覺系統：tokens、字體、版型輪替、元件

原則：**主色從使用者的素材來，結構變化從版型輪替來，質感從克制來。** 不要用「加光暈、加漸層、加卡片」來製造高級感。

## 1. 先寫 design read（一段話，動工前給使用者看）

```text
這是一份 <類型：設計分享／作品集／提案／教學>，給 <受眾>，在 <場景：暗場投影／會議室／線上分享／寄送閱讀> 使用。
視覺語言：<一個明確方向，例如「深綠夜間、技術感但安靜」>；主色取自 <封面／品牌>；
全場高峰是 <哪一頁>；唯一的記憶點（second-read moment）是 <一個做法，全場只用一次>。
```

- 深色或淺色由**場景**決定，不是預設：暗場投影 → 深色；有燈的會議室、螢幕分享、寄送閱讀 → 淺色通常更清楚。決定後整份鎖定，不要每頁換主題（章節頁一次性反轉除外，且要是刻意的）。
- 方向要具體。「乾淨現代」不算方向。

## 2. Tokens（全部寫在 `:root`，頁面裡不寫裸色碼）

| 類別 | 規則 |
| --- | --- |
| 背景 | 3 階：`--bg-0/1/2`，同色相、明度遞增；用低彩度單色漸層或暈影。不用純 `#000`／`#fff`。 |
| 中性色 | 一組灰，往主色相偏 0.005–0.015 chroma（OKLCH）。 |
| 強調色 | **一個**主強調色，只給 1–2 個元素用（重點字、核心結論、目前步驟）。 |
| 語意色 | 最多 3 個（警示／次要／錯誤），只在「狀態、對比、分類」時用，不是裝飾。 |
| 文字 | `--text`（主）、`--text-2`（內文）、`--muted`（註記）。投影環境下內文對比 ≥ 4.5:1，關鍵文字盡量 ≥ 7:1；不要用淺灰「營造高級感」。 |
| 圓角 | 一套：卡片 12–16px、小元件 6–10px、截圖 12px。巢狀時外圈 = 內圈 + padding。不要 ≥ 32px 的卡片。 |
| 陰影 | 只表達高度：細邊框 **或** 小而淡的有色陰影，二擇一。避免「1px 邊框 + 大模糊陰影」的 ghost card。 |
| 間距 | 4/8 倍數。組與組的間距 ≥ 組內間距的 2 倍。舞台安全邊距 80–110px，且每頁標題位置一致。 |
| 動態 | `--ease-out: cubic-bezier(.23,1,.32,1)`、`--ease-in-out: cubic-bezier(.77,0,.175,1)`，見 `motion.md`。 |

主色推導：從封面或品牌取一個色 → 做 `--bg-0`（極暗，L≈8–12%）→ `--bg-1/2` 逐步提亮 → 強調色取同色相高明度高彩度。使用者給了 PPTX 就從封面取色，不要自己發明配色。

**禁用漸層**：紫→藍、粉→橘、彩虹 mesh、霓虹光暈、漸層文字。**可用**：同色相明度漸層、暈影、極淡的 noise。

## 3. 字體

- 中文主體：`"PingFang TC","Noto Sans TC","Microsoft JhengHei",system-ui`（離線也能顯示）。
- Latin：不要預設 Inter／Roboto／Arial。若需要有個性的 Latin 字（數字、英文 kicker），選一個（例：Geist、Satoshi、Manrope），**單一檔案交付時要 subset 並以 base64 `@font-face` 內嵌**，否則就用系統字。
- 等寬字只給程式碼、提示詞標籤、小型 kicker 用，不要整份「工程感」。
- 字型家族 ≤ 2（+ 等寬）。強調用字重或強調色，不換字型、不用斜體（中文沒有真斜體，假斜體很醜）。

**1600×900 舞台字級**（直接用 px，舞台會整體縮放）：

| 角色 | 字級 | 行高 | 備註 |
| --- | --- | --- | --- |
| hero（封面／章節／金句） | 72–96px | 1.1–1.15 | ≤ 2 行 |
| 頁標題 | 44–52px | 1.2–1.3 | ≤ 2 行；`text-wrap: balance` |
| 卡片標題 | 24–30px | 1.35 | |
| 內文 | 19–24px | 1.7–1.8 | `text-wrap: pretty`；每行 ≤ 約 36 個中文字 |
| 註記／圖說 | 15–16px | 1.6 | 不要再小，投影看不到 |
| kicker／標籤 | 13–14px 等寬 | 1 | 字距 .12–.18em，只給 Latin |

- 中文**不加負字距**；負字距只給 Latin 大標（-0.01 到 -0.02em）。
- 數字用 `font-variant-numeric: tabular-nums`。
- **孤字**：段落最後一行只剩 1–2 個字就改寫、調寬或手動 `<br>`，不要靠縮字級。
- **標點懸掛**：行首是「『（時用 `margin-left:-.5em` 讓文字左緣對齊。
- 同一排卡片的標題要對齊：標題長度接近、或固定標題區高度；內文用 `min-height` 對齊。

## 4. 版型家族與輪替規則

每頁在逐頁表中標記一個**版型家族**和一個**構圖錨點**：

| 家族 | 用途 |
| --- | --- |
| Statement | 一句大字（封面、章節、金句、轉折）。 |
| Split | 左文右圖／右文左圖（40/60、50/50）。 |
| Grid | 2–4 張卡片（原因、選項、步驟）。 |
| Full-bleed | 一張大圖或內嵌網站佔滿。 |
| Chat | 提示詞對話＋結果。 |
| Compare | 表格、before/after、A vs B。 |
| Flow | 步驟、流程、時間軸、互動說明。 |
| Quiet | 只有一個數字、一句引言或一張圖，留白很多。 |

構圖錨點：置中、左上、左下壓圖、右三分之一、低置中、偏格線等。

**輪替規則**
- 同一家族不連續超過 2 頁；同一構圖錨點不連續超過 2 頁。「左文右圖」最容易氾濫，不要連用。
- 整份至少 4 種家族；至少 1 頁 Full-bleed 和 1 頁 Quiet（簡約風格的簡報可免 Full-bleed）。
- 高峰頁（通常是 Demo）前一頁要安靜。
- 三張一樣的卡片連排是最典型的 AI 版面：卡片數量依內容決定，能用列表、表格、流程就不要硬做卡片；卡片內不要再套卡片。

## 5. 元件規格（範例 CSS 見 `assets/template.html`）

- **kicker／章節標籤**：只在簡報真的有章節時用（例如 WHY／WHAT／HOW／LEARN），作用是讓觀眾知道自己在哪；不要捏造「SECTION 01」「V0.6 BETA」這種假中繼資料。
- **卡片**：圖示（一致的線條粗細，1.5–1.75）＋標題＋1–2 句。高卡片中段空白時，可放大型圖示徽章（medallion）填空，比拉伸文字好。
- **核心結論框（callout）**：一份簡報只給真正的 takeaway 用，大概 3–6 個；太多就沒有重點。
- **提示詞對話框**：使用者在右、AI 在左，標 ME／AI；提示詞照原文放。長提示詞可縮成摘錄，並在備註放全文。
- **截圖框**：先裁掉瀏覽器外框、作業系統列、空白邊；外框只用細邊框＋圓角，**不要畫假瀏覽器列或假手機外框**。可點擊放大（`data-zoom`）。兩張圖可以做成疊放、點擊切換。
- **比較表**：第一欄是比較維度；用白話和比喻（「像租一間有管家的房子」），不要直接放技術術語；寫具體優點，不寫「效能好」。
- **步驟與截圖同步（viewer）**：左邊步驟列表、右邊截圖，點步驟切換或自動輪播，取代把 5 張截圖擠在一頁。
- **互動說明元件**：用原生前端做小型模擬（快取計數器、設定開關、流程燈號），比靜態圖更好懂；每個互動都要有明確用途。
- **假資料示意**：產品還沒有真實資料時，用 HTML 重做介面並標明是示意，不要把 lorem 或假品牌（Acme、Nexus）放進畫面。
- **圖示**：一套圖示庫、一種線條粗細，跟著文字色。工具內建 Lucide 的離線內嵌腳本；要換 Phosphor 等其他庫也可以，但整份只用一套。不要自己手畫圖示路徑，也不要用 emoji 當圖示。

## 6. 背景與氛圍（克制）

- 背景微互動最多一種主手法：游標聚光、極淡格線遮罩、或與主題相關的粒子網路（例如「埋點事件」→ 節點連線）。要和主題有關，不要裝飾性的光球。
- 低對比、放在文字後面、`pointer-events:none`；`prefers-reduced-motion` 時停止。
- 生成式背景（canvas、p5）要固定 seed，排練和正式看到的一樣；不在畫面上的頁面要暫停。
- 只在封面、章節、結尾用比較強的背景；內容頁讓位給內容。

## 7. AI 味檢查表（出現就修）

- 每頁都有小型大寫 eyebrow／「01 / 06」計數器當裝飾
- 紫藍漸層、漸層文字、霓虹光暈、毛玻璃疊毛玻璃、到處都是光球
- 三張一樣的卡片、卡片套卡片、所有內容都置中
- 編造的數據（+47%、10x faster、99.9%）、假引言、假品牌名
- 文案詞：賦能、無縫、顛覆、打造極致、全方位、一站式（英文：elevate、seamless、unleash、next-gen）
- 每個元素都 hover 放大、每個區塊同一種淡入
- 文字烘焙進圖片（生成圖裡的字不能改、不能被讀出）
- 結尾只有「Thank you」淡出
